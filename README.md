# Cadastro de Alunos

O **Cadastro de Alunos** é um projeto desenvolvido em Java com o objetivo de praticar o uso de **arrays** e a criação de um sistema simples para cadastro e gerenciamento de alunos.

O sistema permite armazenar informações dos alunos e suas notas, possibilitando consultar os dados cadastrados e realizar operações relacionadas ao desempenho dos estudantes.

### Funcionalidades

* Cadastro de alunos;
* Armazenamento dos nomes dos alunos;
* Armazenamento das notas;
* Listagem dos alunos cadastrados;
* Busca de alunos;
* Cálculo de médias;
* Consulta das informações armazenadas.

### Conceitos utilizados

O projeto trabalha principalmente com **arrays**, variáveis, estruturas de repetição, estruturas condicionais, entrada e saída de dados e métodos, ajudando a desenvolver a lógica de programação em Java.

### Objetivo

O objetivo é praticar o uso de **arrays para armazenar e organizar informações**, desenvolvendo um sistema simples de cadastro de alunos e colocando em prática os conhecimentos básicos de programação em Java.
